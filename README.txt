UU的小馆 · 管理员版

使用方法
1. 双击 index.html 或把整个文件夹上传到静态网站托管服务。
2. 点击导航里的「管理员」，密码：UU2026
3. 登录后，你不需要再打开 JavaScript 文件：
   - 「网站文字」：直接修改首页、画廊、一起玩、留言标题、关于等文字；中文和 English 分开编辑。
   - 「每周问题」：每周直接在后台换问题和回答提示。
   - 「我的画」：直接选择图片、填写作品名/日期/分类/说明，然后加入你的画廊。
   - 「投稿审核」：通过后自动出现在「大家的小世界」。
   - 「私信」：访客发来的悄悄话只显示在管理员区。

重要说明
这是一个纯前端静态版本。为了让你现在就能使用，网站内容、投稿和私信使用浏览器 localStorage 保存；因此同一浏览器可以保留数据，但不同访客的浏览器不会共享数据。

管理员密码目前写在前端代码里（UU2026），所以这不是严格意义上的安全管理员系统。正式公开网站时，需要接服务器数据库 + 真正的管理员登录/权限控制，才能保证私信和审核内容真正只有你能看见。
